PersonalAgent for Apple Silicon Macs. Early testing release.

Download the ZIP, extract it, and move PersonalAgent.app to Applications. Quit the previous version before replacing it. Project history remains in ~/Library/Application Support/PersonalAgent/.

This build has an ad-hoc signature for bundle integrity, but is not Developer ID signed or notarized. macOS may block opening it. It is intended for early testers who trust this repository.

SHA256SUMS.txt contains the ZIP checksum. The sidebar announces newer published releases and opens their download page. Installation is manual.
